#  Customer Churn Analysis: Predictive Modeling for Subscriber Retention

##  Project Overview
This project focuses on the **Real-World Problem** of customer churn within the telecommunications industry. The objective is to apply a complete **Data Science Workflow** to predict which customers are likely to leave a service provider based on their usage patterns and demographic data. 
This project uses the Telco Customer Churn dataset to build a predictive model. By performing EDA and applying the Random Forest algorithm, I identified key factors driving customer departures to help businesses improve subscriber retention strategies

Reducing churn is a high-priority "Real-World Problem" as retaining existing customers is significantly more cost-effective than acquiring new ones.

##  Data Science Workflow Applied
As per the course requirements, this project follows the end-to-end workflow:
1.  **Problem Definition:** Identifying at-risk customers to improve retention strategies.
2.  **Data Collection:** Utilizing the **Telco Customer Churn dataset** from Kaggle.
3.  **Data Cleaning & Preprocessing:** Handling missing values in 'TotalCharges', dropping redundant IDs, and formatting data types.
4.  **Exploratory Data Analysis (EDA):** Visualizing churn distribution, contract correlations, and monthly charge impacts.
5.  **Feature Engineering:** Encoding categorical variables and scaling numerical features for model readiness.
6.  **Model Building:** Implementing a **Random Forest Classifier** to handle complex non-linear relationships.
7.  **Model Evaluation:** Using Accuracy, Precision, Recall, and F1-Score to assess performance.
8.  **Visualization of Results:** Plotting Confusion Matrices and Feature Importance charts.

##  Key Insights
* **Contract Type:** Customers on month-to-month contracts exhibit the highest churn rates.
* **Tenure:** New customers are significantly more likely to churn than long-term subscribers.
* **Charges:** High monthly charges are a strong indicator of potential departure.
